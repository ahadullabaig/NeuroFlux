## Formats

- **`*.csv.gz`** files are raw grids, one row per simulation. The plain CSVs a grid writes are gitignored. Analysis scripts read the compressed copies directly and reproduce every table byte for byte. Run `gunzip -k` first if you want to resume or extend a grid.
- **`analysis/`** folders hold the tables the findings documents quote. They are regenerated by that stage's analysis scripts (`analyse_*.py`).
- **`figures/`** folders are regenerated by the stage's figure or analysis scripts (`figures_r3.py`, `figures_r5.py`, and the H1 analysis scripts).
- **`*.db`** files are SQLite, with one `runs` table whose columns follow `RunResult` in `packages/datasets/src/neuroflux_datasets/cli.py`. Query them with `uv run neuroflux-experiment analyze-significance <db> --output-dir <dir>` or `uv run neuroflux-experiment compare <db> <factor> <a> <b> --stratify-by input_snr`.

## Caveats

- The `rpeak_integrity` column in the Phase 3 databases is saturated and deprecated. Use the QRS columns, or `r2_reanalysis/qrs_rescore.db`.
- MIT-BIH input SNRs in Phase 3, R1 and R2 are nominal (see [`docs/r3_findings.md`](../docs/r3_findings.md) §1.6). R3 onwards sets the input SNR exactly.
- MIT-BIH records themselves are not stored here. They are downloaded to the gitignored `data/` directory.
